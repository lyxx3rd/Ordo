# 行级结构标签说明（v1，HN 扩展）

对每个非空行只选择一个标签。保留原文，模型仅输出行号和标签。

| 标签 | 含义 |
| --- | --- |
| `TEXT` | 普通内容，默认值。 |
| `NEW_DOCUMENT` | 新文件的起始标题。 |
| `HEADER` | 跨页重复出现的页眉行，属于非正文信息。 |
| `INFO_PAGE` | 封面、修订记录、编制/审核/批准、版本号等信息页中的非正文元数据行。 |
| `H1` | 正文一级标题。 |
| `H2` | 正文二级标题。 |
| `H3` | 正文三级标题。 |
| `HN` | 最低级小标题, 后续接正文, 禁止包括任何序号 |
| `POINT` | 有明确列表或项目符号格式的并列条目。 |
| `TOC` | 原文件目录中的行。 |
| `TABLE` | 表格中的行。 |
`TABLE` 仅用于实际表格的行；单独出现 `|` 的标题或引导语不是表格。
| `APPENDIX` | 附录。 |

`POINT` 只用于具有明确列表格式的条目，例如项目符号、`1.`、`1、` 等同一列表中的项目。仅以“首先／其次／最后”或“第一／第二／第三”开头的正文论述，即使单独换行，仍标为 `TEXT`。

`HEADER` 仅用于与全局分析中的页眉示例或样式一致、跨页重复出现的行；不要把普通标题、封面标题或只出现一次的元数据标为 `HEADER`。

`INFO_PAGE` 用于信息页中的元数据，不用于正文。封面中的明确文件标题仍标为 `NEW_DOCUMENT`；重复页眉优先标为 `HEADER`。

`H1`／`H2`／`H3` 的层级由编号形式与结构决定，不由出现位置决定。连续出现、编号形式相同且处于同一编号层级的章节必须使用同一标签。
