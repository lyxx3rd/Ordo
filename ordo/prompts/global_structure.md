# 全局结构分析

你将阅读一份完整文本，为后续的逐行结构标注提供全局背景。

只分析下列问题：

1. 文本是否拼接了多份独立文件？
2. 是否存在明确的文章标题？文章标题通常是独立的标题行，不是称呼、目录或正文标题。
3. 若未拼接多份文件且存在明确文章标题，抽取该标题的完整原文；否则填空字符串。不要给出行号；不要改写、概括或虚构标题。
4. 是否存在原文自带目录？
5. 是否存在表格？包含封面修订表及仅剩明确表头的空表；正文外框、无稳定行列关系的流程动作串不算表格。
6. 是否存在明确的附录标记，例如独立的“附录：”行？
7. 正文中是否存在一级标题？若存在，按原文顺序提取所有真实出现的正文一级标题，存入 h1_titles；每项使用原文完整行。不要给出行号；不要改写、概括或虚构标题。
8. 用一句简短说明一级标题的主要形式。若无法确定，填空字符串。
9. 是否存在重复页眉、页脚或明确的独立页码行？统一使用 has_page_header 字段；不要把只出现一次的文章标题、普通章节标题、正文中的比例或日期视为页眉页脚。
10. 若存在，给出一个原文页眉、页脚或页码的具体示例，使用 page_header_style 字段。不要编造原文中没有的字段；若不存在，填空字符串。
11. 是否存在信息页？信息页是主要提供文档元数据、而非正文内容的页面或区块，例如封面、修订记录、编制/审核/批准信息、作者信息、版本号或生效日期；可以有多页。

短元数据区块也算信息页，不要求占满整页。中文、英文及混合语言标题采用同一识别原则，不能因标题为英文而判为无一级标题。

不要做逐行标注，不要输出行号、范围、二级标题或三级标题示例，不要解释推理过程。

只返回合法 JSON，严格使用以下结构：

{
  "has_multiple_documents": false,
  "has_document_title": true,
  "document_title": "关于某事项的意见书",
  "has_page_header": false,
  "page_header_style": "",
  "has_information_pages": false,
  "has_toc": false,
  "has_table": false,
  "has_appendix": false,
  "has_h1": true,
  "h1_titles": ["一、示例一级标题", "二、另一一级标题"],
  "h1_pattern": "以中文序号‘一、’开头"
}

约束：

- 每个 has_* 字段只能为 true 或 false。
- document_title 必须是字符串；仅当 has_multiple_documents 为 false 且 has_document_title 为 true 时填写原文完整标题，其他情况返回空字符串。
- page_header_style 必须是字符串；仅当 has_page_header 为 true 时填写简短的页眉样式，其他情况返回空字符串。
- 信息页只判断是否存在，不要输出页码、行号或信息页示例。
- h1_titles 必须是数组；没有一级标题时返回 []。有一级标题时完整提取，不限于示例或前几条。
- h1_titles 中只能包含原文完整行；同级主章节的识别应贯穿全文一致。排除目录条目、页眉、表格内部编号、二三级标题和普通列表项目。正文主章节与表格内部的编号序列应分开判断。
- h1_pattern 只描述一级标题的可见形式，无法确定时为 ""。
- 一级标题必须是独立的章节名称或概括，本行不承载具体要求、定义、解释或论述；有编号的正文不等于标题。标题和具体正文混在同一行时，不纳入 h1_titles，不拆行或只抽取行内标题片段。
- 标题后仅附“无／（无）”说明章节为空时仍是标题，应保留在对应的一级标题清单中。
- 碎片化标题不得拼接成原文不存在的完整行；只提取可识别的原文行，不补写、修复或虚构标题。
